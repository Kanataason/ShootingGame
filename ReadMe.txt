==================================================
  SHOOTING GAME
==================================================

■ 概要
  C++ と DxLib で作った、2D の縦スクロールシューティングです。
  雑魚敵を倒していくとボスが出現します。ボスを倒すとクリアです。

■ 起動方法
  ShootingGame.exe をダブルクリックしてください。
  exe と同じフォルダに、次のフォルダが必要です。
    ・JsonData
    ・Library\image
    ・Library\Sound

■ 操作方法
  移動            : W / A / S / D
  撃つ            : マウスの左ボタン(押している間、撃ち続ける)
  武器の切り替え  : マウスの右ボタン
  決定            : スペース(タイトル、結果画面)
  終了            : ESC

■ ルール
  ・雑魚敵を一定数倒すと、ボスが出現します。
  ・ボスは HP が 4 割を切ると、第二形態に変わります。
  ・ボスを倒すとゲームクリア、プレイヤーの HP がなくなるとゲームオーバーです。

■ 武器
  ロングショット : 真上にまっすぐ連射します。
  拡散ショット   : 前方に複数の弾をばらまきます。威力は高いが、連射は遅めです。

■ ヒートゲージ
  ・撃つたびにヒートが溜まり、撃たずにいると冷えます。
  ・最大まで溜まるとオーバーヒートし、0 まで冷えるまで撃てなくなります。
  ・撃ち続けず、ときどき止めるのがコツです。

■ 動作環境
  ・Windows 10 / 11(64bit)
  ・画面の大きさに合わせて、ウィンドウの大きさが自動で決まります。
    ウィンドウの端をドラッグして、大きさを変えることもできます。
