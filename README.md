# SHOOTING GAME

C++ と DxLib で作った、2D の縦スクロールシューティングです。
ゲームエンジンを使わず、コンポーネント、ステートマシン、当たり判定、シーン管理などの基盤から自作しています。

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 撃つ | マウスの左ボタン(押している間、撃ち続ける) |
| 武器の切り替え | マウスの右ボタン |
| 決定 | スペース(タイトル、結果画面) |
| 終了 | ESC |

1. 雑魚敵を倒していくと、ボスが出現します。
2. ボスは HP が 4 割を切ると、無敵の時間をはさんで、第二形態に移ります。
3. ボスを倒すとゲームクリア、プレイヤーの HP がなくなるとゲームオーバーです。

### 武器
- **ロングショット**: 真上にまっすぐ、連射します。
- **拡散ショット**: 前方に、複数の弾をばらまきます。威力は高いですが、連射は遅めです。

### ヒートゲージ
- 撃つたびに、ヒートが溜まります。撃っていないと冷えます。
- 最大まで溜まると、オーバーヒートして、0 まで冷えるまで撃てなくなります。
- 押しっぱなしが一番強い状態にならないよう、「撃つ・止める」の判断が生まれるようにしています。

### 敵
| 敵 | 攻撃 |
|---|---|
| 雑魚 1 | プレイヤーを狙って撃つ |
| 雑魚 2 | 全方位に弾をばらまく |
| 雑魚 3 | 壁で跳ね返る弾を、扇状に撃つ |
| ボス | 狙い撃ち、反射弾、全方位を切り替える。第二形態では渦巻き弾が加わる |

## 技術的なポイント

### コンポーネント指向
`GameObject` に、`Movement`、`Attack`、`Status`、`Controller`、`Collider` などのコンポーネントを組み合わせて、プレイヤーや敵を作っています。

### ステートマシン
- プレイヤー、雑魚、ボスの行動を、イベント ID で状態を切り替える `StateMachine` で管理しています。
- どの状態からでも移れる遷移(死亡など)は、`AnyState` から登録します。
- 共通の処理は、基底クラスにまとめています。
  - `TimedState`: 一定時間たったら、次の処理へ移る(無敵、撃破演出)
  - `RandomMoveXState`: 左右のランダムな位置へ移動し続ける
  - `ShotState` / `PlayerShotState`: 一定間隔で撃つ。継承先は、撃ち方だけを書く

ボスの状態遷移:

```
登場 → 第一形態 → (HP 40% 以下) → 無敵 → 第二形態
  └──────────── どこからでも ────────────→ 撃破
```

### データ駆動
敵の出現、ボス、シーン、音を、JSON で定義しています。ビルドし直さずに、調整できます。

| ファイル | 内容 |
|---|---|
| `JsonData/Scenes.json` | シーンの一覧と、置くオブジェクトのファイル |
| `JsonData/GameScene.json` | プレイヤーの設定 |
| `JsonData/Spawn.json` | 雑魚敵のテンプレート(HP、攻撃、画像、当たり判定) |
| `JsonData/Boss.Json` | ボスの設定 |
| `JsonData/Sound.json` | 効果音と BGM のファイル、音量 |

### オブジェクトプール
弾 512 発分のメモリを最初に確保して、使い回しています。撃つたびのメモリの確保と解放をなくしています。

### そのほか
- **当たり判定**: 弾は太さを持った線分として、円や四角形と判定します。コライダー同士の押し戻しは、形の組み合わせごとの関数テーブルで呼び分けます。
- **Event(Observer)**: HP やヒートの変化を、HUD に通知します。ゲームの処理と UI を分けています。
- **描画レイヤー**: 描画を登録だけして、最後にレイヤーの順(背景 → 敵 → プレイヤー → 弾 → エフェクト → UI)でまとめて描きます。
- **シーン管理**: 切り替えは予約だけして、フレームの最初に行います。切り替えるたびに JSON から作り直すので、リトライで最初の状態に戻ります。

## ビルド

### 必要なもの
- Windows 10 / 11(64bit)
- Visual Studio 2022(「C++ によるデスクトップ開発」)

DxLib と nlohmann/json は、リポジトリに入っています。別に入れる必要はありません。

### 手順
1. `ShootingGame.sln` を、Visual Studio で開きます。
2. 構成を **x64** の **Debug** か **Release** にして、ビルドします(Ctrl + Shift + B)。
   - x86(Win32)用の DxLib は入っていないので、x86 ではビルドできません。
3. 実行します(F5)。

- ビルドの後処理で、`JsonData`、`Library/image`、`Library/Sound` が、実行ファイルの隣にコピーされます。exe を直接起動しても動きます。
- JSON、画像、音だけを変えたときは、リビルドしてください(コードに変更がないと、コピーされないことがあります)。
- Release では、DxLib の `Log.txt` を出力しません。
